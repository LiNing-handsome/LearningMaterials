## 数据结构学习手册（PDF）

- **文件**：`数据结构学习手册.pdf`（1659 页，约 15 MB）
- **定位**：计算机考研 408《数据结构》系统学习手册，代码给出 **C / Java / Python** 三种语言实现
- **覆盖范围**：绪论与复杂度分析、线性表、栈/队列/数组、串与 KMP、树与二叉树、二叉排序树/平衡二叉树/哈夫曼树/并查集、图（遍历/MST/最短路/拓扑/关键路径）、查找（折半/B 树/B+ 树/散列表）、排序（内部排序与外部排序）
- **内容构成**：10 个模块 + 附录；476 个完整可运行程序（均经 gcc / javac / python 实际编译运行验证，三语言输出逐字节一致）；50 道 408 考研真题，答案与解析置于各模块文末
- **阅读方式**：PDF 带目录页码（前 4 页）与书签导航（12 个一级 + 78 个二级条目），页脚有页码

> 由 Markdown 源文档转换而成；公式为离线 LaTeX 子集渲染（分式、上下标、根号、组合数、分支式等）。
