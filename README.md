# Learning Materials

本仓库用于帮助计算机爱好者学习计算机相关知识，整理清晰的中文讲解、学习案例、习题和实践资料。资料将持续补充，方便读者按自己的进度学习和复习。

## 学习资料

- [数据结构与算法](Data%20structure/README.md)：从算法基础、线性结构到树、图、查找与排序，配有综合案例、习题索引和公式速查。
- [数据结构学习手册 PDF](Data%20structure/数据结构学习手册.pdf)：适合离线阅读和打印，包含章节目录与题解导航。

后续会按主题增加其他计算机学习资料。欢迎从各主题的 README 开始，先理解原理，再通过案例和练习巩固。

> 资料中的题目来源按实际核验状态标注；未核实的内容不视为历年真题。2027 年官方 408 大纲正文尚未逐项核验。原始题目和原解析不在本仓库发布，PDF 内相关本地备份链接已移除。
